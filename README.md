# Cortijo Velasco - React Application

A modern React application for family management at Cortijo Velasco, rewritten from vanilla JS/Dynamic to React, Vite, TypeScript, and Tailwind CSS.

## Features
- **Public Website**: Home, History, Contact, and External Reservations.
- **Family Access**: Secure family authentication.
- **Calendar & Bookings**: Monthly reservation calendar and audit log.
- **Economic Management**: Expenses and Income tracking by year.
- **Advanced Split (Reparto)**: Year summary (Zona 1) and Transfers/Bizums audit (Zona 2).
- **Inventory**: Complete article tracking by category, location, and responsible family member.
- **Tasks & Maintenance**: Family tasks list and status tracking.
- **Documents**: Official cortijo documents and invoices management.
- **Profile**: Family configuration and percentages.
